# 言い訳コロシアム 面接回答メモ

ポートフォリオサイトには表示せず、転職活動の面接で質問されたときに回答するためのメモです。

## 制作背景

### AWS Summitで変わった、AWSへの印象

以前は、AWSに対してEC2やクラウドサーバーなど、インフラを提供するサービスという印象を持っていました。
AWS Summit 2026で、医療分野のAI活用や、短時間でストーリーを作って遊べるゲームの展示を見たことで、その印象が変わりました。

AWSとAIを組み合わせれば、具体的な体験まで作れる。そのことに興味を持ち、初めてのAWS学習として、Amazon Bedrockを使ったゲームの開発に取り組みました。

## 学んだこと

### サービスをつなぎ、ひとつの処理として捉える

#### AWSの処理フロー

画面からAPI Gateway、Lambda、Amazon Bedrockへ処理が渡り、生成結果が画面へ戻るまでの流れを学びました。

#### 認証と料金対策

公開URLから生成AIを無制限に呼び出されないよう、Cognitoの新規登録を閉じ、管理者が作成したアカウントだけを利用します。

#### AI支援ツールの利用

開発支援にClaude CodeとCodexを利用しました。提案された操作は、目的と影響を確認してから実行しています。
